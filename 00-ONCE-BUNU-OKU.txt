1) WINDOWS'TA BU PAKETİ UYGULA
------------------------------
ZIP dosyasını İndirilenler klasörüne koy. PowerShell'i aç:

cd "C:\Projects"
$project = "C:\Projects\letsgo2travel"
$backup = "C:\Projects\letsgo2travel-yedek-" + (Get-Date -Format "yyyyMMdd-HHmm")
Move-Item $project $backup
Expand-Archive "$env:USERPROFILE\Downloads\letsgo2travel-web-android-final.zip" "C:\Projects" -Force
Move-Item "$backup\.git" "$project\.git"
if (Test-Path "$backup\.env.local") { Copy-Item "$backup\.env.local" "$project\.env.local" -Force }

cd $project
npm ci
npm --prefix mobile ci
npm run lint
npm run build
npm run mobile:prepare:all

Mobil doktor yalnızca `.env.local` geri konmadıysa uyarı verir. Bu durumda mobil AAB
üretmeden önce eski klasördeki gerçek `.env.local` dosyasını geri koy.

2) SUPABASE — YENİ SQL
----------------------
Supabase > SQL Editor'da kökteki şu dosyanın tamamını bir kez çalıştır:

supabase_evening_web_android.sql

Bu migration mevcut gerçek kullanıcı konuşmalarını silmez. Yalnızca eski admin
ekranının ürettiği açıkça sahte demo eşleşmelerini temizler, demo takiplerini gerçek
sağlayıcı aktivasyon kuyruğuna döndürür, 30 günlük kanıt yaşam döngüsünü ve hesap
silme için gerekli güvenli yabancı anahtarları kurar.

Daha önce heartbeat SQL'ini çalıştırmadıysan ayrıca şunu çalıştır:
supabase_visa_worker_heartbeat.sql

-------------------------
VDS terminalinde:

git pull origin main
docker compose -f docker-compose.visa-worker.yml up -d --build --force-recreate

görülmelidir.

6) ANDROID UPLOAD ANAHTARI VE İMZALI AAB
----------------------------------------
Android Studio'da SDK 36 ve JDK 17 kurulu olmalı. Upload anahtarını yalnızca bir kez
oluştur ve güvenli, yedekli bir yerde sakla:

keytool -genkeypair -v -keystore "$env:USERPROFILE\letsgo2travel-upload-key.jks" -alias letsgo2travel-upload -keyalg RSA -keysize 4096 -validity 10000

Aynı PowerShell oturumunda kendi parolalarını gir (bunları dosyaya yazma):

$env:L2T_UPLOAD_STORE_FILE="$env:USERPROFILE\letsgo2travel-upload-key.jks"
$env:L2T_UPLOAD_STORE_PASSWORD="KENDI_KEYSTORE_PAROLAN"
$env:L2T_UPLOAD_KEY_ALIAS="letsgo2travel-upload"
$env:L2T_UPLOAD_KEY_PASSWORD="KENDI_KEY_PAROLAN"

cd "C:\Projects\letsgo2travel"
npm run mobile:prepare
cd android
.\gradlew.bat bundleRelease

Beklenen dosya:
C:\Projects\letsgo2travel\android\app\build\outputs\bundle\release\app-release.aab

`.jks`, parola, `.env.local` ve AAB dosyasını GitHub'a ekleme. Play App Signing'i
etkinleştirip önce İç Test kanalına yükle.

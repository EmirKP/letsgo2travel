POWERSHELL — TEMİZ WEB SÜRÜMÜNÜ UYGULA

PowerShell'i aç ve aşağıdaki komutları sırayla çalıştır:

cd "C:\Projects"
$backup = "C:\Projects\letsgo2travel-yedek-" + (Get-Date -Format "yyyyMMdd-HHmm")
Rename-Item "C:\Projects\letsgo2travel" $backup
Expand-Archive "$env:USERPROFILE\Downloads\letsgo2travel-sabah-guvenlik-guncellemesi.zip" "C:\Projects" -Force
Move-Item "$backup\.git" "C:\Projects\letsgo2travel\.git"
Copy-Item "$backup\.env.local" "C:\Projects\letsgo2travel\.env.local" -Force

cd "C:\Projects\letsgo2travel"
npm install
npm run lint -- --max-warnings=0
npm run build

git status
git add -A
git commit -m "Guvenlik kalite ve worker guncellemeleri"
git push origin main

VERCEL — ÖNERİLEN İKİ GÜVENLİK DEĞERİ

Vercel Project Settings > Environment Variables altında Production, Preview ve
Development için aşağıdaki iki değeri ayrı, uzun ve rastgele metinler olarak ekle:

ADMIN_SESSION_SECRET=En az 32 baytlık rastgele ve ADMIN_PASSWORD'dan farklı değer
ANALYTICS_HASH_SALT=En az 32 baytlık ayrı bir rastgele değer

`ADMIN_SESSION_SECRET` eklenmezse sistem geriye dönük uyumluluk için ADMIN_PASSWORD'u
kullanır; site yine çalışır. `ANALYTICS_HASH_SALT` yoksa IP adresi kaydedilmez.
Bu gizli değerleri mesajla paylaşma. Değerleri ekledikten sonra Vercel'i yeniden deploy et.

VDS — HEARTBEAT'İ BAŞLAT

cd /opt/letsgo2travel
git pull origin main
docker compose -f docker-compose.visa-worker.yml up -d --build
docker compose -f docker-compose.visa-worker.yml ps
docker compose -f docker-compose.visa-worker.yml logs --tail=100 visa-worker

VDS'deki `visa-worker/.env` dosyasında:

API_BASE_URL=https://www.letsgo2travel.com.tr
VISA_WORKER_SECRET=Vercel'deki değerle aynı gizli değer

Gizli değeri mesajla paylaşma.

LETSGO2TRAVEL MOBİL 1.3 — iOS ÖNCELİKLİ KURULUM

ÖNEMLİ

- Uygulama canlı sitenin basit WebView kopyası değildir. Vite ile üretilen ayrı mobil istemci uygulamanın içine gömülür.
- Backend, Supabase ve canlı API adresi https://www.letsgo2travel.com.tr olarak çalışmaya devam eder.
- iPhone simülatörü, fiziksel iPhone derlemesi, imzalama ve App Store yüklemesi için macOS + Xcode gerekir.

1) ORTAK HAZIRLIK

Proje ana klasöründe:

   cd C:\Projects\letsgo2travel
   npm ci
   npm --prefix mobile ci

.env.local dosyasında aşağıdaki genel mobil değerlerin kaynakları bulunmalıdır:

   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...

Bu iki değer Supabase'in istemciye açık URL ve anon anahtarıdır. Service-role anahtarını mobil pakete kesinlikle koymayın.

2) iOS PAKETİNİ HAZIRLA (MAC)

   npm run mobile:prepare
   npm run mobile:ios

mobile:prepare artık iOS önceliklidir. Şunları tek seferde yapar:

- Mobil TypeScript/Vite build
- mobile-dist üretimi
- Capacitor iOS senkronu
- iOS gizlilik, ikon, yönlendirme, sürüm ve yerel paket kontrolü

Xcode açıldıktan sonra:

1. Sol tarafta App projesini seçin.
2. TARGETS > App > Signing & Capabilities bölümünü açın.
3. Apple Developer Team hesabınızı seçin.
4. Bundle Identifier değerinin tr.com.letsgo2travel.app olduğunu doğrulayın.
5. Önce bir iPhone simülatöründe, sonra gerçek iPhone'da Run düğmesiyle test edin.

3) iOS TEK KOMUT KONTROLÜ

   npm run mobile:check:ios

Beklenen sonuç: kritik hata yok. APNs henüz bağlanmadıysa yalnızca Push Notifications uyarısı görülebilir.

4) ANDROID GEREKİRSE

   npm run mobile:prepare:android
   npm run mobile:android

5) SUPABASE AUTH YÖNLENDİRMELERİ

Supabase > Authentication > URL Configuration > Redirect URLs:

   tr.com.letsgo2travel.app://auth/callback
   https://www.letsgo2travel.com.tr/auth/callback
   https://www.letsgo2travel.com.tr/sifre-yenile

Site URL:

   https://www.letsgo2travel.com.tr

iOS'ta Google sosyal girişi varsayılan olarak gösterilmez. Böylece Apple sosyal giriş kuralı için çalışmayan bir seçenek yayınlanmaz. Apple ile giriş Apple Developer ve Supabase tarafında tamamlandığında .env.local içine şu değer eklenebilir:

   VITE_APPLE_AUTH_ENABLED=true

Ardından mobil paket yeniden hazırlanmalıdır.
